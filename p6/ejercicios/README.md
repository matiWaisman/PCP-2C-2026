## Ejecución

Para los archivos que incluyen una función `main`, ejecutá desde la raíz del repositorio. Por ejemplo:

```bash
go run p6/ejercicios/ej1/main.go
go run p6/ejercicios/ej2/main.go
go run p6/ejercicios/ej4a/main.go
```

Para detener un programa que se ejecuta indefinidamente, presioná **Ctrl+C**.
